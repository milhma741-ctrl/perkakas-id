Pertanyaan yang Sering Diajukan

Apakah kata sandi yang dibuat aman? +

Ya. Tool ini memakai Web Crypto API (crypto.getRandomValues), sumber acak kriptografis bawaan browser, bukan Math.random() biasa yang lebih mudah ditebak.

Apakah kata sandi saya tersimpan di suatu tempat? +

Tidak. Kata sandi dibuat dan ditampilkan hanya di perangkat Anda, tidak dikirim atau disimpan di server mana pun.
